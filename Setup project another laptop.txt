URBANEATS - FULL SETUP STEPS FOR ANOTHER LAPTOP

Use this checklist from top to bottom.

==================================================
1) INSTALL REQUIRED SOFTWARE
==================================================
1. Install Node.js LTS (18+ recommended).
2. Install MySQL Server (8+ recommended).
3. Install Git.
4. Install VS Code (optional but recommended).

Check versions:
node -v
npm -v
mysql --version

==================================================
2) GET PROJECT FILES
==================================================
Option A (Git):
git clone <your-repo-url>
cd E-Commerce-web-project

Option B (zip/folder copy):
Copy project folder to laptop, then open it in terminal.

==================================================
3) INSTALL PROJECT DEPENDENCIES
==================================================
Use ONE package manager only.

If using npm:
npm install

If using pnpm:
pnpm install

Note:
Do not run npm and pnpm mixed in normal workflow.

==================================================
4) CREATE .ENV FILE IN PROJECT ROOT
==================================================
Create .env with this content (edit password/secret):

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_mysql_password
PORT=3001
SESSION_SECRET=change_this_to_a_long_random_secret

==================================================
5) START MYSQL SERVICE
==================================================
Start MySQL from Services / XAMPP / MySQL Workbench environment.

If MySQL is not running, backend cannot connect.

==================================================
6) DATABASE/TABLE SETUP
==================================================
No manual table creation required for normal setup.

When backend starts, it auto-creates:
- database: urbaneats
- tables: admins, users, menu_items

If you want manual SQL setup, use:
mysql-table-queries.txt

==================================================
7) START BACKEND API
==================================================
npm run backend

Expected terminal logs:
- UrbanEats backend running at http://localhost:3001
- MySQL database: urbaneats on localhost

If backend fails, check:
- .env DB password
- MySQL service running

==================================================
8) START FRONTEND
==================================================
Use VS Code Live Server (recommended):
1. Open project folder in VS Code
2. Open index.html
3. Click "Go Live"

Default frontend URL is usually:
http://127.0.0.1:5500/index.html
or
http://localhost:5500/index.html

==================================================
9) QUICK HEALTH CHECK
==================================================
Open in browser:
http://localhost:3001/api/health

You should see JSON response.

==================================================
10) ADMIN SETUP / LOGIN
==================================================
Open:
admin-login.html

Behavior:
- If no admin exists: page allows creating first admin.
- If admin exists: login mode appears.

Admin is fully separate from normal user login.

==================================================
11) NORMAL USER SIGNUP/LOGIN
==================================================
Open:
auth.html?mode=signup

Create account fields:
- Username
- Full name
- Email
- Password

Then login via:
auth.html?mode=login
using username + password.

User data is stored in users table.

==================================================
12) CART + CHECKOUT FLOW
==================================================
1. Add items from menu page.
2. Open cart page.
3. Click "Proceed to Checkout".
4. Payment page opens.

==================================================
13) OPTIONAL - FOOD IMAGES
==================================================
Create folder if not present:
food-images

Place local images there, then use filename in admin menu form.

==================================================
14) COMMON PROBLEMS + FIXES
==================================================
Problem: API offline / red indicator
Fix:
- Ensure backend terminal is running
- Check http://localhost:3001/api/health

Problem: Signup button seems not working
Fix:
- Ensure users table exists (backend startup creates it)
- Restart backend after pulling latest code

Problem: CORS/network errors
Fix:
- Open site using localhost/127.0.0.1 URLs
- Avoid file:/// direct opening for auth/admin flows

Problem: Missing modules
Fix:
npm install

==================================================
15) FINAL RUN COMMANDS (DAILY USE)
==================================================
Terminal 1:
npm run backend

Terminal 2:
Open frontend with Live Server

Then use:
index.html for website
admin-login.html for admin panel

END
